# COMP311 Linux OS - Project 2

## Overview

This project was completed as part of the COMP311 Linux OS Laboratory course.

The project focuses on Linux shell commands, shell configuration, process and job concepts, file searching, text processing, and regular expressions.

## Project Objectives

- Working with shell variables and environment variables.
- Creating persistent shell aliases.
- Understanding initialization files.
- Understanding jobs, processes, and parent processes.
- Using the `find` command to search for files, directories, character devices, and symbolic links.
- Redirecting standard output and standard error to files.
- Processing text files using Linux commands and regular expressions.
- Extracting and filtering employee information based on different conditions.
